# WebStudio (desktop version)

This project is a multi-page educational website created about a year and a half ago while learning HTML, CSS (Sass), and basic JavaScript.
This is a concept for a web studio website with several pages and typical sections often used in real-world commercial projects.

The primary focus was on layout, page structure, and understanding how to build a full-fledged static website without frameworks or CMS. The project helped reinforce Sass, Flexbox, and basic interactivity using pure JavaScript.

## What's in the project

The project features a multi-page structure with a separate home page, portfolio page, and additional section. It includes sections for services, work samples, team, and clients, as well as a footer with a subscription form. A modal window with a contact form is used for user interaction.
Visually, the website is built on a responsive layout and a neat grid, using Google Fonts, SVG icons, and hover effects for project cards.

## Technologies Used

The project is built in HTML5 with semantic markup, the styles are written in CSS3 using Sass, and the interactive portion is implemented in pure JavaScript. Flexbox is used for alignment and layout of elements, and Modern Normalize is enabled for cross-browser stability.
